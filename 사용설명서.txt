# 설교 쇼츠 만들기 도구

유튜브에 올린 설교 영상에서 원하는 부분을 골라 **세로형 쇼츠(1080×1920)**로 만들어 주는 무료 도구입니다.
제목·성경 본문·자막·교회 이름·설교자 이름을 자동으로 넣고, 말 사이의 빈틈을 줄여 속도감 있게 이어 줍니다.

<img src="docs/완성화면_예시.png" width="300" alt="완성 화면 예시">

- 설교 영상에서 필요한 부분만 고화질로 내려받습니다(전체 영상을 받지 않습니다).
- 단어 사이의 빈틈(무음)을 자동으로 줄여 말이 빠르게 이어집니다.
- 음량을 유튜브 기준(-16 LUFS)에 맞추고, 배경음악을 목소리보다 작게 깔 수 있습니다.
- 마지막 1.5초는 화면과 소리가 함께 부드럽게 사라집니다.
- 자막 파일(.srt)도 함께 만들어집니다.
- 윈도우와 맥에서 쓸 수 있습니다. 프로그램 실력이 없어도 따라 할 수 있도록 만들었습니다.

---

## 이 링크를 받으셨나요? 아래 순서대로 하시면 됩니다

**처음 한 번만** 1~4단계를 하시고, **그다음부터는 매주** 「매주 쇼츠 만들기」만 하시면 됩니다.

준비물
- 윈도우 또는 맥 컴퓨터
- 유튜브에 올린 설교 영상 (**공개** 또는 **일부공개**. 비공개는 안 됩니다)
- 챗GPT, 클로드, 제미나이 같은 AI 채팅 (무료 버전도 됩니다)

### 1단계. 도구 내려받기

1. 이 링크를 누르면 바로 내려받아집니다: **[설교쇼츠도구 내려받기 (ZIP)](https://github.com/hahadark/sermon-shorts-tool/releases/latest/download/sermon-shorts-tool.zip)**
2. 내려받은 ZIP 파일을 **마우스 오른쪽 버튼 → 「압축 풀기」(모두 압축 풀기)** 합니다.
3. 나온 「설교쇼츠도구」 폴더를 바탕화면이나 문서 폴더처럼 찾기 쉬운 곳에 둡니다.

### 2단계. Python 설치하기 (처음 한 번만)

이 도구는 Python이라는 무료 프로그램 위에서 돌아갑니다.

1. https://www.python.org/downloads/ 에 들어가 노란색 **Download Python** 버튼을 눌러 설치 파일을 받습니다.
2. **윈도우**: 설치 첫 화면 아래쪽의 **「Add python.exe to PATH」에 반드시 체크**한 다음 「Install Now」를 누릅니다.
   이것을 빼먹으면 다음 단계가 안 됩니다. 빼먹었다면 설치 파일을 다시 실행해 「Modify」에서 체크하거나, 지우고 다시 설치하세요.
3. **맥**: 받은 파일을 열어 계속 「계속」을 누르면 됩니다.

### 3단계. 필요한 프로그램 설치 (처음 한 번만)

- **윈도우**: 「설교쇼츠도구」 폴더 안의 **`설치_윈도우.bat`** 를 더블클릭합니다.
  파란 경고창(Windows의 PC 보호)이 나오면 **「추가 정보」 → 「실행」**을 누르세요.
- **맥**: 「터미널」 앱을 열고 `bash ` (bash 뒤에 한 칸 띄우기)를 입력한 뒤,
  **`설치_맥.command`** 파일을 터미널 창으로 끌어다 놓고 엔터를 누릅니다.

검은 창에 글자가 지나가다가 마지막에 **「모두 준비되었습니다」**가 나오면 끝입니다.

### 4단계. 우리 교회 정보 넣기 (처음 한 번만)

폴더 안의 **`설정.json`** 을 메모장(맥은 텍스트 편집기)으로 열어 고칩니다.
**따옴표(")와 쉼표(,)는 지우지 마시고, 따옴표 안의 글자만 바꾸세요.**

```json
{
  "교회이름": "우리교회",
  "설교자": "담임목사 홍길동",
  ...
}
```

- `"교회이름"`: 화면 아래에 나올 교회 이름
- `"설교자"`: 교회 이름 아래에 나올 설교자 (비워 두면 안 나옵니다). 회차마다 바꿀 수도 있습니다.
- `"배경음악"`: 배경음악 파일 위치. 예) `"배경음악/piano.mp3"` (비워 두면 배경음악 없음)
  → 「배경음악」 폴더에 파일을 넣고 이름을 적으면 됩니다. **사용 허락을 받은 음원만 쓰세요.**
- `"단어사이_공백_줄이기"`: `true`면 말 사이 빈틈을 자동으로 줄입니다. 원래 속도를 원하면 `false`.

그 밖에
- **로고**: 교회 로고(배경이 투명한 PNG)를 폴더에 **`로고.png`** 라는 이름으로 넣으면 교회 이름 왼쪽에 나옵니다. 없으면 이름이 가운데로 갑니다.
- **글꼴**: 「글꼴」 폴더에 원하는 글꼴(.ttf / .otf)을 하나 넣으면 그 글꼴로 만듭니다. 없으면 함께 들어 있는 나눔고딕으로 만듭니다.

## 매주 쇼츠 만들기

**`실행_윈도우.bat`** 를 더블클릭합니다. (맥은 터미널에 `bash ` 입력 후 `실행_맥.command` 를 끌어다 놓고 엔터)
아래 메뉴가 나옵니다.

```
1. 대본 받기 (유튜브 주소 입력)
2. 미리보기 그림 만들기
3. 쇼츠 영상 만들기
4. 설치 점검
```

### ① 대본 받기
메뉴에서 **1** → 설교 영상의 **유튜브 주소**를 붙여 넣고 → 회차 이름을 적습니다 (예: `2026-11-01_하나님중심의기도`).
「회차」 폴더 안에 그 이름의 폴더가 생기고 다음 파일이 들어 있습니다.
- `대본.txt` : 설교 전체 자동 자막 (시간 포함)
- `단어시간.txt` : 단어마다 시작 시간
- `회차.json` : 편집 정보 (다음 단계에서 채웁니다)

※ 영상을 올린 직후에는 유튜브 자동 자막이 아직 없을 수 있습니다. 몇 시간 뒤에 다시 하세요.

### ② AI에게 편집 정보 만들어 달라고 하기
1. **`AI편집요청문.txt`** 를 열어 `[ ]` 부분(설교 제목, 본문, 유튜브 주소, 원하는 길이)을 이번 주 내용으로 바꿉니다.
2. 챗GPT·클로드 같은 AI 채팅에 그 내용을 붙여 넣고, **`대본.txt` 와 `단어시간.txt` 를 첨부**해서 보냅니다.
3. AI가 준 JSON(중괄호 `{ }`로 된 부분)을 복사해 회차 폴더의 **`회차.json` 에 통째로 덮어쓰고 저장**합니다.
4. AI가 "고친 자동 자막"이라고 알려 준 부분은 실제 설교를 듣고 맞는지 꼭 확인하세요.

요청문에는 이런 편집 원칙이 들어 있습니다: 설교의 결론과 적용 중심으로 고르기, "그…" 같은 군말과
회중에게 묻는 말("누구입니까?")은 빼되 문맥은 이어지게 하기, 설교자가 하지 않은 말을 만들지 않기.

### ③ 미리보기 (처음이나 카메라 위치가 바뀌었을 때)
메뉴에서 **2** → 회차 번호 선택.
회차 폴더의 「미리보기」 폴더에 완성 화면 그림 3장과 `원본_자르기영역.png` 가 생깁니다.

<img src="docs/자르기영역_예시.png" width="480" alt="자르기 영역 예시">

빨간 네모가 쇼츠에 들어가는 부분입니다. 설교자가 네모 가운데에 오지 않으면 `설정.json` 의 `"화면자르기"` 숫자를 고칩니다.
- `x` 를 키우면 네모가 오른쪽으로, `y` 를 키우면 아래로 갑니다.
- `너비` 를 줄이면 더 크게 확대됩니다. (세로 길이는 자동)

### ④ 쇼츠 영상 만들기
메뉴에서 **3** → 회차 번호 선택. 2분짜리 기준 보통 1~3분이면 끝납니다.
회차 폴더의 **「완성」 폴더**에 영상(.mp4)과 자막(.srt)이 생깁니다.

고칠 곳이 있으면 `회차.json` 을 고치고 ④만 다시 하면 됩니다. (이미 받은 영상은 다시 받지 않습니다)

### ⑤ 유튜브에 올리기
유튜브 스튜디오에서 「만들기 → 동영상 업로드」로 완성 영상을 올립니다.
처음에는 **일부공개**로 올려 링크로 확인한 다음, 괜찮으면 **공개**로 바꾸는 것을 권합니다.

## 자주 생기는 문제

| 이런 말이 나오면 | 이렇게 하세요 |
|---|---|
| `python` 을 찾을 수 없다 / 창이 바로 닫힌다 | 2단계의 「Add python.exe to PATH」 체크를 확인하고 Python을 다시 설치하세요. |
| 유튜브에서 영상을 받지 못했습니다 | 주소와 공개 설정(공개/일부공개)을 확인하세요. 그래도 안 되면 **`설치_윈도우.bat` 를 다시 실행**해 내려받기 프로그램을 최신으로 바꾸세요. 유튜브가 바뀌면 자주 필요합니다. |
| 한국어 자막을 찾지 못했습니다 | 업로드 직후에는 자동 자막이 없습니다. 몇 시간 뒤 다시 하세요. |
| 회차.json 파일의 형식이 잘못되었습니다 | 알려 준 줄 근처의 쉼표·따옴표·괄호를 확인하세요. AI에게 "JSON 형식만 다시 확인해 줘"라고 해도 됩니다. |
| 자막 시간이 구간 밖에 있습니다 / 순서가 잘못되었습니다 | 알려 준 구간의 자막 시간을 고치세요. |
| 글자가 화면 밖으로 넘친다 | 그 자막을 둘로 나누거나 `\n` 으로 줄을 바꾸세요. (한 줄 18자 안팎) |
| 말이 너무 빨라 숨 쉴 틈이 없다 | `설정.json` 에서 `"단어사이_공백_줄이기": false` 로 바꾸세요. |
| 영상 길이가 예상과 다르다는 오류 | 회차 폴더 안의 `_원본` 폴더를 지우고 ④를 다시 하세요. |

막히면 메뉴의 **4번(설치 점검)**을 실행해 어떤 항목이 빠졌는지 확인하세요.

## 회차.json 형식 (직접 고칠 때)

```json
{
  "제목": "나라와 권세와 영광이\n아버지께 있사옵나이다",
  "성경": "마태복음 6:13",
  "설교자": "담임목사 홍길동",
  "영상": {"유튜브": "https://www.youtube.com/watch?v=xxxx"},
  "구간": [
    {
      "시작": "57:34.54",
      "끝": "57:41.96",
      "자막": [
        ["57:34.54", "기도란 시작도 하나님이요"],
        ["57:38.80", "끝도 하나님이심을\n가르쳐 주십니다"]
      ]
    }
  ]
}
```

- 구간은 적은 순서대로 이어 붙습니다. 시간은 **원본 유튜브 영상 기준**입니다 (`"57:34.54"` = 57분 34.54초, 1시간이 넘으면 `"1:24:00.86"`).
- 자막은 `[표시 시작 시간, 글자]` 이고, 다음 자막 시간까지 보입니다. 두 줄은 `\n` 으로 나눕니다.
- 제목이 두 줄이면 `\n` 으로 나눕니다.
- 선택 항목: `"교회이름"`, `"배경음악"`(`""` 이면 이번 회차만 없음), `"파일이름"`, `"화면자르기"`, `"단어사이_공백_줄이기"`, `"컷지점_자동다듬기": true`
- 유튜브 대신 컴퓨터의 영상 파일을 쓰려면 `"영상": {"파일": "C:/영상/설교.mp4"}` (이 경우 대본은 따로 준비해야 합니다)

명령어로도 쓸 수 있습니다 (맥은 `python3`):
```
python shorts.py 점검
python shorts.py 대본 <유튜브주소> <회차폴더이름>
python shorts.py 미리보기 <회차폴더이름>
python shorts.py 만들기 <회차폴더이름>
```

## 꼭 지켜 주세요

- **우리 교회가 권리를 가진 설교 영상만** 쓰세요. 다른 교회·방송의 영상을 허락 없이 쓰면 안 됩니다.
- 글꼴과 배경음악은 **사용 허락(라이선스)을 받은 파일**만 쓰세요. 구매한 음원이라도 다른 사람에게 파일을 넘겨주는 것은 따로 허락이 필요할 수 있습니다.
- 찬양이 들어간 부분은 저작권 문제가 생길 수 있으니 설교 부분만 쓰는 것을 권합니다.

## 사용하는 것들
- Python, [Pillow](https://python-pillow.org/), [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)(FFmpeg), [yt-dlp](https://github.com/yt-dlp/yt-dlp) — 모두 무료입니다.
- 함께 들어 있는 나눔고딕 글꼴(`_기본글꼴` 폴더)은 SIL 오픈 폰트 라이선스(`_기본글꼴/OFL.txt`)를 따릅니다.
- 이 도구의 코드는 MIT 라이선스입니다. 자유롭게 쓰고 고쳐서 나누셔도 됩니다.
